One line, the funniest honest error message an appliance could show: a washing machine that has walked itself across the kitchen floor chasing one wet towel, and is now warning its owner before it reaches the neighbours. The laugh comes from the fault itself — an unbalanced load really does make a washer vibrate and wander — told in the machine's own flat, put-upon voice.

## Run it

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The program checks the gate itself before writing: a single line, 1–200 characters, not blank. It takes no input, uses no network, no randomness and no clock, so every run writes byte-identical output.
